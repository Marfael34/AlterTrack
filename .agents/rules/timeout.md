# Règle de Timeout Opérationnel (300s)

Si une étape, une commande shell, un script ou une tâche dure plus de 300 secondes (5 minutes), l'interrompre immédiatement et passer à autre chose (approche alternative, solution de contournement ou étape suivante) afin de ne jamais bloquer le flux de travail ni faire attendre l'utilisateur.
